# plans/

Specs and implementation plans for work that spans sessions. Name files after the feature
(`<feature>.md` for the design spec, `YYYY-MM-DD-<feature>-plan.md` for the execution plan).
Plans live **here**, never in a machine-local path — collaborators and future sessions must
be able to open them. When reality diverges from a plan, add a dated "Superseded in one
respect" note at the top and link the DECISIONS entry; don't rewrite the plan's history.
